Возможности

🖥

Десктоп-приложение

Windows-приложение на Python: каталог из 110 услуг с фильтрами по каждому столбцу, управление заявками, отчёты «Услуги по категориям», «Заявки за период», «Доход по категориям» в форматах Excel и TXT.

📱

Мобильное приложение

Android-приложение на Flet: поиск и фильтры каталога, карточка услуги с описанием, оформление заявки в пару касаний, список заявок со статусами и раздел статистики.

☁️

Синхронизация через облако

Обе программы работают с одной базой данных MySQL в облаке: заявка, созданная на телефоне, сразу видна на ПК, а изменение статуса на ПК мгновенно появляется в мобильном приложении.

О проекте

КонсалтПро — информационная система для консалтинговой компании: справочник услуг с категориями, ценами, единицами измерения и сроками оказания; заявки клиентов с рабочим процессом (новая → в работе → завершена/отменена); аналитика и отчёты.

  • Стек: Python 3.13, CustomTkinter, Flet, MySQL (Clever Cloud), PyInstaller, Gradle/Android SDK
  • Данные: 110 услуг в 6 категориях, 50 заявок, фильтры по каждому полю
  • Разработка: десктоп, мобильное приложение, база данных, сайт и отчёт
